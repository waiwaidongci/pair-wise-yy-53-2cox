# 影视内容发行权窗口与独占冲突审阅平台

源提示词编号：10。维护作品、权利类型、地区、语言、窗口、独占和次级授权，联动时间轴与地区矩阵，检测重叠、交叉、倒挂和独占冲突，支持批量调窗、版本差异、评论锚点、审批和追溯导出。

## 批次与语言轨规则

- 独占判定键为「作品 × 地区 × 语言」：普通话字幕窗口与粤语配音窗口不再互相遮挡。
- 窗口携带语言、批次号（batchId）与批次序号（seq）；同一作品/地区/语言的时间重叠独占在同一批次内按序号先到先得，后到窗口置为「留待核验」，需改期、改语言或解除独占。
- 授权窗口、条款意见、审批快照在同一批次提交（`commitBatch`）。日期、独占或语言改动后，未完成意见立即标记「已失效」并按当前窗口重算系统意见；全部意见处理完且留待核验窗口清零后，才能导出审批包。
- 审批包只引用同批次冻结快照（含指纹），提交后再改动会使快照过期，须重新提交；写入失败后按批次号幂等重试，不重复写入。
- 旧窗口缺少语言时迁移补成「普通话」，缺少批次号归入历史批次。
